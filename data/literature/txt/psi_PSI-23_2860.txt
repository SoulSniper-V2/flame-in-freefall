8.0           Output FILES
8.1           Data Output File
Data output files are created using the SystemOpenTestPoint command which creates a file named and stored at
/payload/sci/testpointName_x/testpointName_x_data.csv, where testpointName is the parameter received in the
SystemOpenTestPoint command and _x is optional to avoid duplicate files, where x = 1,2,3, etc.
The file contains a two-line header. The first line has the date and time, documentation of the setup received in a
SystemDefineSetup command, and the PMT gains. The second line has the column headings for the subsequent rows of data. The
text of the column headings is defined by the Diagnostics/Header registry entry or the Diagnostics/BreHeader entry depending on
whether the SystemDefineSetup command experimentType parameter was BRE or not. The column headings should match the data
which is the following:

       -   A timestamp in the format HH:MM:SS:mmm, where mmm is milliseconds.
       -   11 channels of analog input from the cube DNx-AI-207 board in the order shown in Table 1.
       -   25 channels of analog input from the cube DNx-AI-225 board in the order shown in Table 2. (The names of
           many of these values change depending on whether it is a BRE test or not, hence the two options for header.)
       - Channel AO-4 of the DNx-AO-333 analog output board. This is the E-Field control voltage.
Rows of comma-separated data is added to the file between DataRecordingStart and DataRecordingStop commands at a
rate defined by the Diagnostics/SampleTimeMsec registry entry, see Error! Reference source not found., defaulting to 8
msec for 125 Hz sampling.

8.2          Message Log File
Software messages are logged to files named and stored at /payload/logs/YYYY-MM-DD_hh-mmACME.log, where YYYY
is year, MM is month, DD is day of month, hh is hour, and mm is minutes. The date in the name is when the log file is
created, soon after software startup.
Each message line in the file begins with a timestamp and a logging category. The timestamp is of the format YYYY-MM-
DD DDD hh:mm:ss:mmm, where DDD is day of the year, mmm is milliseconds, and the rest are self-explanatory. See
section Error! Reference source not found. for information about the logging category and how to filter them out if
desired.

8.3          Command Log File
The message log file, section 8.2, includes messages showing commands received and their parameters. Command log
files contain only the details of each command received. The files are named and stored at /payload/logs/YYYY-MM-
DD_hh-mmACMECommands.log. The format is for each command received a timestamped line of text with the
command name followed by timestamped lines of text showing each parameter name and parameter value, including
header information.
